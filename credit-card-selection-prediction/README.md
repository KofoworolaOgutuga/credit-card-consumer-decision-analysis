# Credit Card Selection Prediction for Consumer Decision-Making

## Overview

This academic data mining project focuses on predicting whether a respondent will choose the dominant or preferred credit card based on consumer characteristics and marketing-related variables.

The project uses the dataset `cred_card.xlsx` and applies data preparation, exploratory data analysis, and predictive analytics to investigate consumer credit card selection.

The objective is to translate analytical findings into meaningful business insights and recommendations.

## Project Objectives

The objectives of this project are to:

* Prepare and clean the dataset for analysis.
* Explore consumer characteristics and relevant variables.
* Investigate factors associated with credit card selection.
* Apply and evaluate three data mining techniques.
* Compare analytical results where appropriate.
* Develop business insights and actionable recommendations.
* Communicate the methodology and findings through a written report and presentation.

## Dataset

**Dataset filename:** `cred_card.xlsx`

The dataset contains information used to analyze consumer credit card selection.

Variables identified in the project instructions include:

* Demographic characteristics
